- 命名：`YYYY-MM-DD-序号-内容.jpg`，例 `2026-11-18-01-全家福.jpg`
- 本目录**入库**（`docs/` 不被忽略）；单张压到 1MB 内，别把仓库撑大
- 采集数据 / rosbag / 模型权重仍放 `data/`，不入库

## 安全提醒（W2 先验，别抢跑）

- **W2 只接 USB**，不接 24V、不接电机——那是 W3 的事
- A4988 插反或带电插拔会烧驱动，装前先断电
- 串口权限：Ubuntu 里先 `sudo usermod -aG dialout $USER`，注销重登才生效
